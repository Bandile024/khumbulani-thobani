HOW TO ADD YOUR VIDEO AND PLANNER PHOTO IN VS CODE
==================================================

1. HOME PAGE HERO VIDEO:
   Place your video file inside this `public/` folder and name it:
   public/hero-video.mp4

2. ABOUT THE PLANNER IMAGE:
   Place your photo inside this `public/` folder and name it:
   public/planner-photo.jpg

(Or, if your files have different names, edit `CUSTOM_MEDIA` at the top of `src/data/planningData.ts`.)
